## 🚀 Featured Project

### 🔐 [Web Application VAPT Assessment – OWASP Juice Shop](https://github.com/adithyan-p-s/web-application-vapt-assessment)

A practical web application security assessment conducted in a controlled local lab environment using OWASP Juice Shop.

| | |
|---|---|
| **Tools** | Nmap, Gobuster, Burp Suite, Kali Linux, Docker |
| **Confirmed finding** | SQL Injection leading to Authentication Bypass (`POST /rest/user/login`) |
| **Severity** | Critical |
| **Deliverables** | Recon and enumeration output, screenshots, finding write-up, PDF report |

**Assessment activities**

- Reconnaissance using Nmap
- Directory enumeration using Gobuster
- HTTP request and response analysis using Burp Suite
- SQL injection and authentication security testing
- Evidence collection and security findings documentation
- Professional VAPT report preparation

*Scope: local, intentionally vulnerable lab only. A focused learning project, not a full penetration test.*
